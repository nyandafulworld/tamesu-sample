    No.03 — AUTOMATION RULES

    自動化ルール

    「きっかけ → 条件 → 動作」の3本で、確認作業の一部を自動化します。

    01

    高リスクの注文 → 自動で保留し、担当者に通知

    きっかけ

    注文のリスク分析が完了する

    条件

    リスク判定が「高」

    動作

    発送を自動で保留し、担当者へ通知する

    標準機能 手動運用

    02

    本人確認が未完了 → 発送を保留

    きっかけ

    注文が作成される

    条件

    会員に「本人確認済み」の目印が無い

    動作

    発送を保留にする

    標準機能 個別開発

    03

    承認済み会員 かつ 低リスク → 発送承認待ちへ

    きっかけ

    注文のリスク分析が完了する

    条件

    会員が「承認済み」かつ リスク判定が「低」

    動作

    「発送承認待ち」の一覧に表示する（最終確認は担当者）

    標準機能 手動運用

    自動化の土台はShopify Flow

    「高リスクの注文が来たら自動で保留してスタッフに知らせる」といった業務の自動化は、Shopify Flowという標準ツールで作れます。ただし一部の高度な機能は契約プランによって使える・使えないが分かれます。

    NOTE

    3つのルールはいずれも通知先を担当者にしています。会員ごとに内容が異なる審査結果メールを、Shopify Flow単体でお客様へ自動送信することはできないためです。お客様へのご案内は別の仕組みと組み合わせて検討します。

    お客様ごとに異なるメールの自動送信

    注文確認・発送通知などの定型メールは標準機能で自動送信できます。ただし審査結果のようにお客様ごとに内容が変わるメールの自動送信には、アプリや外部サービスとの連携など別の仕組みが必要です。
